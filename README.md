# 三國倖存者（原型）

三國題材、手機橫向、2.5D 合作倖存者遊戲原型。介面以圖像為主，採低彩度莫蘭迪配色；目前人物和場景使用程式建立的立體示意模型，正式圖檔可再替換。

## 目前包含

- 8 分鐘一場的原型節奏，地圖約為可視畫面的 3 × 3 倍。
- 斜角與較高俯視兩種鏡頭角度。
- 6 人房間上限、公開房快速加入、建立房間、房主鎖房和邀請連結。
- 房間內玩家位置即時同步；WASD／方向鍵與手機虛擬搖桿。
- 房主負責模擬共享敵人與戰鬥；全隊位置、敵人、隊伍生命和升級進度會同步。
- 擊倒敵人累積絕技能量；精英敵人更耐打、威脅更高，擊倒後提供較多經驗與能量。
- 隊伍生命耗盡會提前結束；蓄滿能量可施放大範圍攻擊。
- 敵人會掉落生命或能量補給，玩家必須移動靠近拾取；補給位置會同步，並在一段時間後消失。
- GitHub、Three.js、Cloudflare Workers / Durable Objects 的免費工具方向。

## 本機預覽

需要 Node.js。安裝免費 Wrangler CLI 後：

```sh
npm install
npm run dev
```

Wrangler 會在本機模擬 Worker、靜態資產和 Durable Object。要發布到 Cloudflare Workers：

```sh
npx wrangler login
npm run deploy
```

使用免費方案時，請在 Cloudflare 控制台確認 Worker 維持 Free；免費額度用完時，連線功能可能暫時無法使用。

## 第一版範圍

目前是可檢視的連線原型，不是完成版：房主瀏覽器模擬敵人與自動攻擊，再由 Durable Object 同步戰鬥狀態；房主離線時，新房主會從最近一次同步狀態繼續。正式版仍建議將戰鬥模擬移到伺服器，並以你提供的角色、技能和介面圖檔替換示意模型。

## 圖檔替換

目前沒有綁定任何付費素材。之後可提供角色立繪、技能圖示、主畫面背景或場景素材，再依實際圖檔尺寸與格式整理進 `public/assets/`。
