# 三國倖存者（合作原型）

以《三國演義》為題材的瀏覽器合作倖存者遊戲。畫面採手機橫向、低彩度莫蘭迪配色和斜角 2.5D 場景；目前人物、場景、圖示與音效由程式即時產生，方便先驗證玩法流程。

## 目前可玩的內容

- **12 分鐘一場**：普通敵人逐步增加，約 3、7、10 分鐘出現三段首領；打倒最後首領才能勝利。
- **四名角色**：劉備偏支援、曹操偏重擊、孫權偏快速遠程、呂布偏近戰重攻擊。角色可在大廳選擇，擁有不同移動與戰鬥特性、絕技。
- **個人升級**：各自取得經驗並從三個技能強化圖示中選一項；選擇時不會暫停其他玩家。
- **敵人與首領**：一般兵、快速兵、遠程兵、精英兵和首領，各有不同移動、生命與威脅範圍。
- **個人生命與救援**：玩家倒地後，隊友可在倒數內靠近救援；全隊無人能戰鬥時遊戲失敗。生命與絕技能量補給會同步。
- **三張地圖主題、三種難度**：林地、軍營、城池；房主可在大廳設定。房間可設定 2、4 或 6 人上限。
- **公開房間**：快速加入或瀏覽可加入房間；房主可鎖房。符合條件時，進行中的前六分鐘可加入；邀請連結可直接帶入房間。
- **連線恢復**：短暫斷線會保留 30 秒角色，期間可用原連線身分回到房間；房主離開時會移交房主權限。
- **操作與介面**：電腦支援 WASD／方向鍵，手機支援虛擬搖桿；有斜角及較高俯視視角切換、必要 HUD 和音效開關。

## 技術與本機預覽

GitHub 存放原始碼，Cloudflare Worker + Durable Objects 處理房間 WebSocket 與狀態同步，靜態遊戲檔案由 Worker Assets 提供。原型由房主瀏覽器模擬敵人和戰鬥，再同步房間狀態；正式營運前應將權威戰鬥模擬移到伺服器。

需要 Node.js：

```sh
npm install
npm run dev
```

部署前先在 Cloudflare 登入，並可用以下命令檢查部署包：

```sh
npx wrangler deploy --dry-run
npm run deploy
```

`npm run check` 會檢查 Worker 與前端 JavaScript 語法。Cloudflare 免費方案的可用額度與限制以帳戶控制台為準。

## 美術素材狀態

目前是玩法原型，幾何人物、場景裝飾、技能圖示與 Web Audio 音效都是程式示意素材，尚未達到 RO 類型的正式 2.5D 美術品質。下一階段需要統一風格的四名角色模型及動作、敵兵與首領模型、三張地圖環境素材、技能圖示，以及背景音樂與音效。可先由你提供角色／場景圖檔或美術方向，再按素材清單接入；原型沒有依賴付費素材。
